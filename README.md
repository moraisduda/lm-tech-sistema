# 🚀 LM Tech - Sistema de Gestão

Sistema web moderno, responsivo e otimizado para gestão, desenvolvido com tecnologias nativas e suporte a Progressive Web App (PWA).


🌐 *Acesse o projeto online:* [lm-tech-sistema.vercel.app](https://lm-tech-sistema.vercel.app)

--

## 🛠️ Tecnologias Utilizadas

- *HTML5:* Estruturação semântica e acessível.
- *CSS3:* Estilização moderna, responsiva e alinhada com a estética dark/tech.
- *JavaScript (ES6+):* Lógica dinâmica e interatividade.
- *PWA (Progressive Web App):* Suporte para instalação e navegação otimizada.
- *Vercel:* Hospedagem e deploy contínuo.

—

## 📱 Recursos e Funcionalidades
- 💻 *Design Responsivo:* Adaptado para telemóveis, tablets e computadores.
- ⚡ *Alta Performance:* Carregamento rápido sem dependência de frameworks pesados.
- 📱 *Instalável (PWA):* Pode ser adicionado ao ecrã principal como uma aplicação nativa.
